    Markdown Features Starter¶

    A small docs site built from plain .md files. Every page demonstrates GUI features that plain Markdown on GitHub cannot do, such as tabs, callouts, copy buttons, diagrams, and a search box.

    Get started See the features

    What is inside¶

    • Copy buttons

      Every code block gets a copy icon automatically. Try it on Getting Started.

    • Tabs and switchers

      Switch between Windows, macOS and Linux instructions in one click.

    • Callouts and collapsibles

      Notes, warnings, tips and expandable sections. See Callouts.

    • Diagrams and math

      Mermaid flowcharts, Gantt charts and LaTeX equations. See Diagrams and Math.

    • Code block extras

      Line numbers, highlighted lines, titles, diffs and annotations. See Code Blocks.

    • Interactive bits

      Custom buttons, copy-to-clipboard for any text, and more. See Interactive Bits.

    Built-in features you get for free¶

    • Full-text search (top right)
    • Light and dark mode toggle (top right)
    • Sidebar and table of contents built from your headings
    • Hover anchor links on every heading
    • Mobile-friendly layout
    • Your own content (that is the next step)

    Where to go next

    Open any .md file in the docs/ folder, change some text, and save. If mkdocs serve is running, the page refreshes by itself.
