    Text, Layout and Media¶

    Text styling¶

    Bold, italic, bold italic, strikethrough, highlighted, underlined, H2O (subscript), x2 (superscript).

    Keyboard keys: Ctrl+C to copy, Ctrl+V to paste, Cmd+Shift+P for the command palette.

    Abbreviation tooltip: the HTML spec is maintained by the W3C. Hover over the abbreviations to see their meaning.

    Smart symbols: © ™ ® ± ≠ → ← ↔ ½ ¾.

    Emoji and icons:

    Status indicators: 🟢 ready, 🟡 in progress, 🔴 blocked.
