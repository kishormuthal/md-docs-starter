# Markdown Features Starter

A small docs site built from plain `.md` files. Every page demonstrates GUI
features that **plain Markdown on GitHub cannot do**, such as tabs, callouts,
copy buttons, diagrams, and a search box.

[Get started](getting-started.md){ .md-button .md-button--primary }
[See the features](features/callouts.md){ .md-button }

## What is inside

<div class="grid cards" markdown>

- :material-content-copy: **Copy buttons**

    ---

    Every code block gets a copy icon automatically.
    Try it on [Getting Started](getting-started.md).

- :material-tab: **Tabs and switchers**

    ---

    Switch between Windows, macOS and Linux instructions in one click.

- :material-alert-circle-outline: **Callouts and collapsibles**

    ---

    Notes, warnings, tips and expandable sections.
    See [Callouts](features/callouts.md).

- :material-chart-timeline-variant: **Diagrams and math**

    ---

    Mermaid flowcharts, Gantt charts and LaTeX equations.
    See [Diagrams and Math](features/diagrams-math.md).

- :material-code-braces: **Code block extras**

    ---

    Line numbers, highlighted lines, titles, diffs and annotations.
    See [Code Blocks](features/code.md).

- :material-gesture-tap-button: **Interactive bits**

    ---

    Custom buttons, copy-to-clipboard for any text, and more.
    See [Interactive Bits](features/interactive.md).

</div>

## Built-in features you get for free

- [x] Full-text search (top right)
- [x] Light and dark mode toggle (top right)
- [x] Sidebar and table of contents built from your headings
- [x] Hover anchor links on every heading
- [x] Mobile-friendly layout
- [ ] Your own content (that is the next step)

!!! tip "Where to go next"

    Open any `.md` file in the `docs/` folder, change some text, and save.
    If `mkdocs serve` is running, the page refreshes by itself.

!!! info "Make it yours"

    Use the round :material-cog: button at the bottom right (or press ++alt+t++)
    to switch themes, change colors, zoom, font and page width. See
    [Theme Lab](theme-lab.md) for details.
